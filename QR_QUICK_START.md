# QR Code Quick Start Guide

## 🚀 Get Started in 3 Steps

### For Patients

#### Step 1: Get Your QR Code
```
Profile → "Show My QR Code" button → Download/Share
```

#### Step 2: Add a Doctor
**Option A - Scan Doctor's QR:**
```
Doctors → "Scan Doctor QR Code" → Camera/Gallery → Done!
```

**Option B - Manual Entry:**
```
Doctors → Enter doctor's email → "Add Doctor"
```

---

### For Doctors

#### Step 1: Get Your QR Code
```
Profile → "Show My QR Code" button → Download/Share
```

#### Step 2: Add a Patient
**Option A - Scan Patient's QR:**
```
Patient Management → "Add Patient" → "Scan Patient QR Code" → Done!
```

**Option B - Manual Entry:**
```
Patient Management → "Add Patient" → Enter Health ID → "Link Patient"
```

---

### For Admins

#### Find Any User Instantly
```
All Users → "Scan QR" button → Scan user's QR code → View Details
```

---

## 📱 Scanning Options

### 🎥 Camera Mode
- Point camera at QR code
- Hold steady until scan completes
- Works with phone/tablet/webcam

### 🖼️ Gallery Mode
- Click "Gallery" tab in scanner
- Select QR code image from device
- Upload and scan instantly

---

## 💡 Pro Tips

### 1. Share Your QR Code
- Download from profile
- Share via WhatsApp, Email, SMS
- Print for clinic/office display

### 2. Best Scanning Practices
- ✅ Good lighting
- ✅ Hold camera steady
- ✅ Clear, unobstructed QR code
- ✅ Try gallery upload if camera fails

### 3. Quick Connections
- Doctors: Display QR at reception
- Patients: Show QR during consultation
- Admins: Scan for instant user lookup

---

## 🎯 Common Use Cases

### Use Case 1: New Patient Registration
```
1. Patient visits clinic
2. Doctor scans patient's QR code
3. Patient instantly added to doctor's list
4. Start consultation immediately
```

### Use Case 2: Doctor Discovery
```
1. Patient sees doctor's QR on clinic poster
2. Patient scans QR code with phone
3. Doctor added to patient's account
4. Can book appointments/send messages
```

### Use Case 3: Admin User Management
```
1. Admin needs to find specific user
2. User shows QR code (or admin has image)
3. Admin scans QR code
4. User profile opens instantly
```

## ❓ Troubleshooting

### Camera Not Working?
→ Switch to "Gallery" tab and upload QR image

### QR Not Scanning?
→ Check lighting, hold steady, or try gallery upload

### User Not Found?
→ Verify QR code is from HealthHub user
